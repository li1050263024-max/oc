# OC 设定抽卡器

像素风微信小程序：随机抽取 OC（原创角色）设定（姓名、种族、发色、瞳色、性格、怪癖），以卡片展示，支持复制文案、保存图片与分享。

## 运行方式

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 用微信开发者工具打开本项目目录 `oc`
3. 使用「预览」或「真机调试」在手机上体验（或使用模拟器）

无需配置 AppID，选择「测试号」或「游客模式」即可本地运行。

## 如何修改选项池

所有随机选项都在 **`data/pools.js`** 中维护，与业务代码解耦。

- 打开 `data/pools.js`
- 按需增删或修改以下数组中的字符串即可，无需改其他文件：
  - **names**：OC 姓名
  - **races**：种族
  - **hairColors**：发色
  - **eyeColors**：瞳色
  - **personalities**：性格
  - **quirks**：怪癖

规则：每个维度独立、等概率随机；各维度之间不绑定。保存后重新编译/刷新即可生效。

## 功能说明

- **抽卡**：从 6 个维度各随机 1 项，组成一张 OC 设定卡
- **再抽一次**：重新随机并刷新结果
- **复制文案**：将当前设定复制为一段文字，便于粘贴到笔记或聊天
- **保存图片**：将当前设定卡生成图片并保存到相册（需授权相册权限）
- **分享**：通过右上角菜单分享给好友/群聊，标题会带上当前 OC 姓名与种族（若有结果）
